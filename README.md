# overfitting-rigidbody-rtx3050

'본인만의 수치적분법(Numerical Integration)을 물리 시뮬레이션에 적용하는 텀프로젝트'로 대체합니다. 아래의 상세 내용을 확인하여 일정에 차질이 없도록 준비해 주시기 바랍니다.



1. 평가 기준

시뮬레이션의 완성도는 아래 3가지 항목을 기준으로 평가하며, 만족도가 높을수록 고득점을 부여합니다.

시간 간격(Time-step)의 강인성: 타임스텝이 커져도 시뮬레이션이 터지지 않고 안정적으로 유지되는가
강성(Stiffness)의 강인성: 높은 강성 값에서도 수치적 불안정성 없이 안정적인 거동을 보이는가
거동의 사실성: 실제 물리 현상과 얼마나 유사하고 사실적으로 표현되는가

2. 평가 시나리오 (총 3개)

제공된 템플릿 프로젝트 내의 모든 시나리오(총 3종)에서 본인의 수치적분법이 정상 작동하고 위의 평가 기준을 만족해야 합니다.

천(Cloth) 시뮬레이션: 중력(Gravity) 조건 하에서만 구동 및 평가
볼륨 메쉬(Volume Mesh) 시뮬레이션: 중력(Gravity) 조건 하에서만 구동 및 평가
1자유도(1-DoF) 스프링 시뮬레이션: 사용자 입력(User Input)에 따른 외력이 작용하는 상태에서 구동 및 평가


3. 프로젝트 세팅 및 당일 평가 안내

프로젝트 실행: 첨부된 압축파일을 해제한 후, Unity Hub에서 [프로젝트 추가]를 통해 실행하시면 기본 템플릿 환경(평가용 씬)이 세팅됩니다.
온라인 과제 제출
제출 기한: 6월 4일 16시 30분까지 (기한 엄수)
제출 파일
본인이 수치적분 로직을 구현한 스크립트 파일 (.cs)
본인이 시도한 방법론 및 핵심 알고리즘을 정리한 발표 자료 (.pdf 또는 .pptx)
수업 시간 평가 및 지참 안내
평가 일시: 6월 4일 수업 시간

당일 수업 시간에 본인이 시도한 수치적분법에 대한 발표 평가와 템플릿 프로젝트에 스크립트를 적용하여 실시간으로 구동하는 대면 코드 검사가 동시에 진행됩니다.

학생 분들은 온라인으로 제출한 스크립트 파일(.cs)과 발표 자료(PPT)를 USB 메모리에 저장하거나, 본인의 이메일/드라이브 등에 업로드하여 수업 시간에 지연 없이 바로 불러올 수 있도록 준비해 오시기 바랍니다.
